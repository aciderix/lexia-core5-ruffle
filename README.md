# Lexia Core5 Reading - Ruffle Web Edition

Offline web version of Lexia Core5 Reading (v1.1.5.131) running via Ruffle (Flash emulator).

## How it works

- SWF content extracted from the original installer
- AMF server calls bypassed with mock responses
- Runs entirely in the browser, no server needed
- Progress saved via Ruffle SharedObject (localStorage)

## Play

Visit the GitHub Pages URL to play in your browser.
